# Krishora Insight

Local prototype scaffold for the registered product **Krishora Insight**.

This tree is a FastAPI template. It is not an agriculture product yet. Identity target is Shared Hosted Core. Product data target is self-hosted Postgres. Do not treat `agriculture/insight/` as this repo. **Krishora** (the family name) is Future and lives only as the shell `agriculture/main`.

```bash
uv run uvicorn app.main:app --reload
```
